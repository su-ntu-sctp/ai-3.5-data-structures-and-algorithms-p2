# 3.5 Self Studies

**Estimated Preparation Time:** 65 minutes

## Task 1 — Trees and Binary Trees (25 minutes)

Watch the following video on Trees and Binary Trees in Java:

- 📹 [Trees and Binary Trees in Java: (https://www.youtube.com/watch?v=qH6yxkw0u78&t=738s)]
  
While watching, refer to **lesson.md Parts 2 and 3** and pay attention to:
- The difference between a regular tree and a binary tree
- Key terms: root, parent, child, leaf, edge
- How a binary tree limits each node to at most two children

**Guiding Questions:**
1. What makes a Binary Tree different from a regular Tree?
2. Can a root node have a parent? Why or why not?
3. Give a real-world example where a tree structure would be a natural fit.

---

## Task 2 — Searching and Sorting Algorithms (25 minutes)

Watch the following video on Linear Search and Bubble Sort:

- 📹 [Linear Search in Java — https://www.youtube.com/watch?v=246V51AWwZM]
  

- 📹 [Bubble Sort in Java — https://www.youtube.com/watch?v=Dv4qLJcxus8]
  

While watching, refer to **lesson.md Parts 4 and 5** and pay attention to:
- How Linear Search steps through each element one by one
- How Bubble Sort compares adjacent elements and swaps them
- What Big O notation means and why O(n) vs O(n²) matters

**Guiding Questions:**
1. What happens in a Linear Search if the element is not in the array?
2. After one full pass of Bubble Sort, where does the largest element end up?
3. Why is Bubble Sort described as O(n²) complexity?

---

## Task 3 — Recursion (15 minutes)

Watch the following video on Recursion in Java:

- 📹 [Recursion in Java — https://www.youtube.com/watch?v=ivl5-snqul8]
  

While watching, refer to **lesson.md Part 6** and pay attention to:
- What a base case is and why it is essential
- How a recursive method calls itself with a smaller input each time
- What happens if you forget to include a base case

**Guiding Questions:**
1. In your own words, what is recursion?
2. What is the base case in the factorial example?
3. What error occurs if a recursive method has no base case?
